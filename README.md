# 🌐 DOM Practice

Ejercicios de manipulación del DOM con JavaScript, hechos siguiendo la lección **Foundations** de [The Odin Project](https://www.theodinproject.com/).

## 📁 Contenido

| Carpeta | Qué practiqué |
|---|---|
| `basicDomManipulation/` | Ejemplo base de la lección: seleccionar y modificar elementos |
| `domJs/` | Crear elementos solo con JS: un párrafo rojo, un `h3` azul y un `div` rosa con hijos |
| `shopping-list/` | Lista de compras dinámica: agregar y eliminar items, validar el campo vacío y devolver el foco al input |

## 🧠 Conceptos usados

- `querySelector`, `createElement`, `appendChild`
- `textContent` y `style`
- `addEventListener` y `preventDefault`
- `remove()` y `focus()`

## ▶️ Cómo probarlo

Cada carpeta tiene su propio `index.html` y `script.js`. Abrí el `index.html` de la que quieras ver en el navegador (o con Live Server en VS Code).
